# Actor and Movie Data Tracker
Allows users to input movies from a list that they would like to know the common actors from. \
Allows users to input actors and question what movies from the list they have been in and with what other actors.

# Skills used
-accessing outside files\
-using |,^, and & to represent informational commands

# How to Run
1. Make sure movies.txt is downloaded or that any other movies are formatted the same way
2. python search.py
